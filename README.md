# Yan Wang — personal website

Biological sciences edition, 10 September 2026. Published at https://yanwang-yale.github.io/.

This static website includes my research experience, CV, photographs and an independent cross-species spatial transcriptomics project. The dedicated torpor and cognition interest maps are omitted from this edition.

Serve this folder with any static HTTP server. Spatial data load only when the viewer is opened. The right-hand marmoset panel switches between official atlas coordinates and a 47-section reconstruction.

The spatial models present data from the Allen Brain Cell Atlas and Marmoset Single Cell Atlas. Dataset sources and coordinate descriptions are available inside the viewer.
